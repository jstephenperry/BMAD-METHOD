Continuous Agile 是一个 AI 驱动的开发框架，覆盖从构思、规划到智能体实施的完整软件交付流程。它提供专业智能体、引导式工作流和可随项目复杂度调整的智能规划，无论是修复 bug 还是构建企业级平台都适用。

如果你已经习惯使用 Claude、Cursor 或 GitHub Copilot 这类 AI 编码助手，现在就可以开始。

## 新手入门？先从教程开始

理解 Continuous Agile 的最快方式是亲自尝试。

- **[Continuous Agile 入门教程](./tutorials/getting-started.md)** — 安装并理解它如何工作
- **[工作流地图](./reference/workflow-map.md)** — BMM 阶段、工作流与上下文管理的全景视图

:::tip[只想直接上手？]
安装 Continuous Agile 后运行 `bmad-help`，它会根据你的项目状态和已安装模块给出下一步建议。
:::

## 如何使用这些文档

这些文档按你的目标分成四个部分：

| 部分 | 用途 |
| --- | --- |
| **教程** | 学习导向。通过分步引导带你做成一件事。第一次使用建议从这里开始。 |
| **操作指南** | 任务导向。解决具体问题的实用文档，例如“如何自定义智能体”。 |

## 扩展与自定义

想用自己的智能体、工作流或模块扩展 Continuous Agile？由 BMad Code, LLC 发布的 **[BMad Builder（英文）](https://github.com/bmad-code-org/bmad-builder)** 提供了创建自定义扩展所需的框架与工具，无论是添加能力，还是从零构建新模块都可以。

## 你需要准备什么

Continuous Agile 可与任何支持自定义系统提示词或项目上下文的 AI 编码助手配合使用，常见选择包括：

- **[Claude Code](https://code.claude.com)** — Anthropic 的 CLI 工具（推荐）
- **[Cursor](https://cursor.sh)** — AI 优先的代码编辑器
- **[Codex CLI](https://github.com/openai/codex)** — OpenAI 的终端编码智能体

你需要了解一些基础软件工程概念，例如版本控制、项目结构和敏捷工作流。即使没有使用过这类智能体系统，也可以从这些文档开始上手。
